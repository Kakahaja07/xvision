How does the Twitter character counter count characters?

The Twitter Character Counter counts a post the way X does. The standard limit is 280, every link counts as 23 characters, and emoji plus Chinese, Japanese and Korean characters count as 2. It follows the open-source twitter-text rules that X publishes, so the total matches X closely.

Here's why that matters. A plain counter might call a post with a long link 290 characters when X counts far fewer. A post full of emoji can look short but run over. Counting the X way avoids both.

How to use the Twitter Character Counter

  1. Type or paste your post into the box at the top of the page.
  2. Watch the first number. It shows how many of the 280 characters you have used.
  3. Check characters left. It turns amber when you are close and red when you are over.
  4. Look at the bar. It fills as you type and turns red past the limit.
  5. Read the note below the numbers. It tells you how many links it found, each counted as 23.
  6. Edit until you are under 280, then copy your text into X.

How does X count characters?

X uses weighted counting. Most characters count as 1, some count as 2, and links count as a fixed 23 no matter how long they are. Photos and GIFs count as 0. The rules live in the open-source twitter-text project.

The exact numbers sit in the twitter-text v3 config file. It sets the max weighted length to 280, gives most characters a weight of 2, and lists ranges that weigh 1. Links are swapped for a 23 character length, and emoji are parsed as single units.

What you typeCounts as
English letters, numbers, spaces and line breaks1 each
Accented Latin, Greek, Cyrillic, Arabic, Hebrew, Hindi (Devanagari) and Thai letters1 each
Dashes and curly quotes1 each
Chinese, Japanese and Korean characters2 each
Emoji, including ones with a skin tone2 each
Any link, short or long23
Photos and GIFs0

So a Japanese post fits about 140 characters, not 280. That is by design. Those scripts pack more meaning into each character.

What is the character limit on X in 2026?

The standard limit on X is 280 characters per post, as of October 2026. Paid subscribers can write longer posts, but X's own help pages disagree on how long. One page says up to 25,000 characters and another still says 4,000.

X's How to Post page confirms the 280 limit for everyone. Anyone can read a long post, but only subscribers can create one. Because the two help pages give different numbers for long posts, I'd treat "far more than 280" as the safe answer and test it in your own composer.

This counter checks against 280, the limit every account shares. If you run over without a paid plan, trim the post or turn it into a thread.

Example: counting a post with a link and an emoji

Here's a fictional post from a small app maker:

"Shipped dark mode for our notes app today 🌙 Full changelog: https://example.com/changelog/dark-mode-launch"

It has 106 characters if you count them one by one. The counter shows 84. The 46 character link counts as 23, and the moon emoji counts as 2. That leaves 196 characters free for a sentence about why dark mode matters.

Tips for fitting more into 280 characters

  • Lead with the point. Readers decide fast, and early words carry the post.
  • Cut filler like "I just wanted to say" and "really". It rarely adds meaning.
  • Paste the full link. Shortening it won't save anything, since X counts every link as 23.
  • Use emoji on purpose. Each one costs 2, so three decorative emoji eat 6 characters.
  • Use line breaks freely. Each one costs only 1 and makes the post easier to scan.

Common mistakes to avoid

  • Trusting a plain character counter. It counts a long link at full length and may get emoji wrong.
  • Squeezing words together to save spaces. It makes a post harder to read for a tiny gain.
  • Assuming every language counts the same. Chinese, Japanese and Korean text uses the limit twice as fast.

Frequently Asked Questions

Do spaces count as characters on Twitter?

Yes, spaces count as characters on Twitter (X). Each space and each line break uses 1 of your 280 characters, the same as a letter. The Twitter Character Counter includes them in its total. Removing extra double spaces can save a few characters, but keep the spaces that make the post readable.

Do emojis count as 2 characters on Twitter?

Yes, most emoji count as 2 characters on X under the open-source twitter-text rules. That includes emoji with a skin tone, which are counted as one emoji. Three emoji in a post use 6 characters. The Twitter Character Counter applies the same weighting so you can see the real cost.

Does a link count against the 280 character limit?

Yes, every link counts against the limit, but always as 23 characters, whether the web address is short or very long. X swaps links for a fixed length when it counts. That means you never need a link shortener to save space, and a long link costs the same as a short one.

Do photos and GIFs count toward the character limit?

No, photos and GIFs do not count toward the character limit on X. The X Help Center says photo and GIF attachments use none of your characters on iOS, Android, x.com and mobile web, as of October 2026. You can add images and still use all 280 characters for text.

Why does my count differ from other character counters?

Your count differs because most counters treat every character the same. X gives links a fixed 23, counts emoji and Chinese, Japanese and Korean characters as 2, and counts photos as 0. A plain counter misses those rules, so it can show a post as too long or short when X disagrees.
