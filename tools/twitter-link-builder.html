How do you create a Twitter share link?

To create a Twitter share link, add your text to X's post intent URL, https://x.com/intent/tweet, with parameters like text, url, hashtags and via. A Twitter link builder does the encoding for you. Anyone who clicks the link sees the X composer with your words already filled in, ready to edit and post.

I first needed one of these for a newsletter footer. Hand-typing %20 for every space got old fast, and one missed ampersand broke the whole link. The builder above shows the encoded link as you type, so you can test it before it goes anywhere.

How to use the Twitter link builder

  1. Pick a link type: Share post, Follow, Profile or Search.
  2. For a share link, type the post text, then add an optional link, hashtags and a via account.
  3. For follow or profile links, type the handle, with or without the @.
  4. For a search link, type the words people should see results for.
  5. Check the live link and the character estimate. Red text means something needs fixing.

What are the X web intent link formats?

X web intents are plain links that open an X action, like writing a post or following an account, without any app setup. X's developer docs list these formats in the Web Intents overview (checked in October 2026):

LinkFormat
Share postx.com/intent/tweet?text=...&url=...&hashtags=...&via=...
Followx.com/intent/follow?screen_name=handle
Profilex.com/handle
Searchx.com/search?q=words

The post web intent docs explain each share parameter. Text must be URL-encoded. The url must be a full http or https address, and X shortens it with t.co. Hashtags are a comma-separated list without the # sign. The via account is added as "via @username". X also says the combined text, link, hashtags and via should stay within 280 characters, or people must edit before posting. The profile and search links are simply X's normal page addresses, not intents.

Plain link or X button: which HTML should you use?

Use the plain link if you want speed and privacy, and the X button if you want X's familiar styled button. The plain link is just an anchor tag. It loads nothing from X until someone clicks.

The button version adds the twitter-share-button or twitter-follow-button class and loads X's widgets.js script, which turns the link into a styled button. That script comes from X's servers, so it adds a request to your page. X's docs also note that web intents can't load inside an iframe, so link to them directly.

Common link builder mistakes

  • Typing the # in hashtags. The intent expects names only, like "saas,buildinpublic". The builder strips the # for you.
  • Using a link without https. The url parameter needs a full address.
  • Writing a full 280 character post. Leave room for the link, hashtags and the person's own comment.
  • Never testing the link. Click Open test link once before you publish it anywhere.

Frequently Asked Questions

Do Twitter share links still work after the rename to X?

Yes, Twitter share links still work, and X's developer docs now list the post intent at https://x.com/intent/tweet as of October 2026. The path still uses the word "tweet". This Twitter link builder uses the x.com format, which opens the X composer on the web or in the X app when it is installed.

Does the person need to be logged in to use a share link?

No, they don't need to be logged in before clicking. X's Web Intents overview says a viewer gets the chance to log in or create an account before finishing the action. After that, X shows the composer or follow prompt, and the person still decides whether to post or follow.

Can a share link post automatically for someone?

No, a share link never posts by itself. It only opens the X composer with text already filled in. The person can edit or delete every word, and nothing goes live until they press Post. That is why web intents need no app setup, passwords or permissions from the person clicking.

Why does my share link show the wrong text?

A share link shows the wrong text when special characters are not URL-encoded. An unencoded ampersand, hash or question mark cuts the text short or breaks the link. The Twitter link builder encodes every character with encodeURIComponent, so copy the link from the tool instead of editing it by hand afterward.

Is this Twitter link builder free?

Yes, the Twitter link builder is free and needs no sign-up. It builds share, follow, profile and search links plus HTML snippets right in your browser. Nothing you type is uploaded or stored, and the only time X is contacted is when you click the test link yourself.
