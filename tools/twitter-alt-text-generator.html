Twitter Alt Text Generator

Answer a few short questions about your image and get three clear alt text options for X, each with a live count against the 1,000 character limit.

    This tool can't see your image. It writes from your answers only, and nothing is uploaded.

    How do you write alt text for a Twitter image?

    To write alt text for a Twitter image, describe what matters in it: the main subject, what is happening, the setting and any text it shows. A Twitter alt text generator guides you through those questions and builds clear options. X allows up to 1,000 characters per image description, as of October 2026.

    A blank alt text box can feel like homework, so a lot of people skip it. Breaking it into five small questions makes it easier. Each answer takes a few seconds, and the sentence almost writes itself.

    How to use the Twitter alt text generator

    1. Pick the image type: photo, screenshot, chart, meme or text graphic. The questions change to fit the type.
    2. Describe the main subject in a few words, like "a small brown dog with a red collar".
    3. Add what is happening and where. Keep it to what you can see.
    4. Type any text in the image. For screenshots and text graphics, this is the most important field.
    5. Add why you are sharing it if the post doesn't already say so.
    6. Pick the option that sounds best, check the character count and click Copy.
    7. Click "Try other wording" if you want different phrasing.

    One honest note: this tool can't see your image. There's no image recognition here. It turns your answers into clean sentences, which also means it never guesses wrong about what is in your photo.

    How do you add alt text on X?

    Add alt text on X while you write the post, before you publish. X's guide on making images accessible gives these steps (as of October 2026):

    • iPhone and Android app: attach your photo, tap the +Alt button on the image, type the description and tap Done.
    • x.com on desktop: attach your photo, click Add description, type it and click Done.

    You can add a separate description to each image in a post, and you can edit it until you post. X's help page also notes that image descriptions cannot be added to videos, so for a video, describe the key moment in the post text instead.

    What should good alt text include?

    Good alt text says what someone would miss if they couldn't see the image. X's own advice on writing great image descriptions covers the core rules: capture what's important, stay objective, write out text in the image, mention when something is a screenshot, and don't start with "photo of".

    Image typeFocus on
    PhotoWho or what, the action, the setting
    ScreenshotSay it's a screenshot, then the app and the key text
    Chart or graphChart type, topic, main trend, time range
    MemeThe picture, the caption and the joke
    Text graphicThe full text, word for word

    The 1,000 character limit is a ceiling, not a target. Most photos need one or two sentences. Charts and text graphics can need more.

    Alt text examples

    These are made-up examples to show the pattern.

    • Photo: "A small brown dog with a red collar leaps to catch a green tennis ball on a wet beach at sunset."
    • Screenshot: "Screenshot of the settings page of a budgeting app on a phone, showing the new dark mode switch turned on."
    • Chart: "Line chart of weekly newsletter signups from January to March 2026. Signups rise steadily and double from 120 to 240."

    Common alt text mistakes

    • Starting with "image of". Screen readers already say it's an image.
    • Leaving out the words. Text inside an image is invisible to a screen reader unless you type it out.
    • Adding opinions. Write "smiling at the camera", not "looking adorable".
    • Using alt text for hashtags or jokes. It is for describing the image, and everyone can read it.
    • Repeating the post. If the post names the book, the description can focus on the cover.

    Frequently Asked Questions

    What is the alt text character limit on X?

    The alt text limit on X is 1,000 characters per image, as listed in X's help center in October 2026. That is far more than most images need. X's guidance still asks you to be succinct, so aim for one or two clear sentences for a photo and save longer descriptions for charts or images full of text.

    Does this alt text generator use AI to look at my image?

    No, this alt text generator does not look at your image at all, and nothing is uploaded. It is a guided writer. You answer questions about the subject, action, setting, visible text and purpose, and the tool turns those answers into clear sentences using templates. That way the description always matches what you actually see.

    Can I add alt text after posting on X?

    X's help center describes adding and editing image descriptions in the composer before you post, as of October 2026. To be safe, write the description before you publish. If you forget, the usual fix is to delete the post and post it again with the alt text added, before it collects replies.

    Can I add alt text to a video or GIF on X?

    X's accessibility help page says image descriptions cannot be added to videos, as of October 2026. For a video, put a short description of the key moment in your post text or add captions to the video itself. Check the composer for GIFs, since X can change which media types support descriptions.

    Should alt text include hashtags or my handle?

    No, alt text should only describe the image. Hashtags, handles and jokes belong in the post. Screen reader users hear every character you add, so extra tags make the description longer and harder to follow. The one exception is text that actually appears in the image, which you should type out as written.
