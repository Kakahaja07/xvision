    How do you add UTM parameters to a Twitter link?

    To add UTM parameters to a Twitter link, attach tags like utm_source=x, utm_medium=social and utm_campaign=your_campaign to the end of the page URL. A Twitter UTM generator builds and checks the tagged link for you. Google Analytics then shows which X posts, bios or ads sent each visitor to your site.

    Without tags, traffic from X often shows up as one vague referral line. I learned that the hard way after a launch week, when I couldn't tell if visits came from the pinned post, the bio link or a reply. Tagging each link took two minutes and fixed it.

    How to use the Twitter UTM generator

    1. Paste the page URL you want to share, like your pricing page or a blog post.
    2. Keep utm_source as "x", or type the name your team already uses.
    3. Pick utm_medium: "social" for normal posts, "paid_social" for ads.
    4. Name the campaign, like "spring_launch".
    5. Optionally add utm_content to tell links apart, like "bio_link" or "pinned_post".
    6. Choose how to handle spaces and capitals, then copy the tagged link.
    7. Click Save to list to keep several versions side by side while you work.

    What does each UTM parameter mean?

    Each UTM parameter answers one question about a visit: where it came from, which channel, which campaign and which link. Google's help page on collecting campaign data with custom URLs says to always use utm_source, utm_medium and utm_campaign.

    ParameterAnswersExample for X
    utm_sourceWhich site sent the visit?x
    utm_mediumWhich marketing channel?social or paid_social
    utm_campaignWhich campaign or promo?spring_launch
    utm_contentWhich link or creative?pinned_post
    utm_termWhich paid keyword?Usually blank on X

    Google's page also lists utm_id and a few newer fields for ad platforms. For everyday posts, the five above are enough.

    Why should UTM values be lowercase?

    UTM values should be lowercase because Google Analytics treats them as case sensitive. Its help page says utm_source=google and utm_source=Google count as two different values, and it recommends lowercase as a standard. So "X", "x" and "Twitter" would split your X traffic into three rows.

    That is why the generator lowercases values and replaces spaces by default. Spaces turn into %20 in a URL, which looks messy and is easy to mistype later. An underscore or a hyphen is cleaner. Pick one style and stick with it.

    UTM naming examples for X

    These are made-up examples for a fictional app called Tallybook.

    • Bio link: utm_source=x, utm_medium=social, utm_campaign=evergreen, utm_content=bio_link
    • Launch thread: utm_source=x, utm_medium=social, utm_campaign=v2_launch, utm_content=thread_post_1
    • Promoted post: utm_source=x, utm_medium=paid_social, utm_campaign=v2_launch, utm_content=video_ad_a

    Keeping the campaign name the same across organic posts and ads lets you compare them in one report. X shortens links with t.co, so a long tagged URL does not eat extra room in your post.

    Common UTM mistakes

    • Mixing names. "x", "twitter" and "X.com" in the same report. Write your naming rules down.
    • Tagging links to x.com. UTM tags only report on sites where you run analytics.
    • Tagging internal links. Links between pages on your own site should stay untagged.
    • Doubling tags. Pasting a URL that already has UTM tags and adding more. The generator replaces old tags instead.

    Frequently Asked Questions

    Should I use x or twitter as the utm_source?

    Either works, as long as you use the same value every time. This Twitter UTM generator defaults to "x" because the platform is called X today. If your old reports already use "twitter", keep it so your history stays in one row. Mixing both splits the same traffic into two sources.

    Do UTM parameters affect how my post looks on X?

    No, UTM parameters do not change how the link preview looks in most cases, because the card comes from the page itself. X shortens links with t.co, so the long tagged URL does not use extra characters in your post. The tags only matter once someone lands on your site.

    Are my links saved or sent anywhere?

    No, nothing leaves your browser. The Twitter UTM generator builds links on your device, and the saved list exists only in memory for this tab. Close or refresh the page and the list is gone, so use Copy all to keep your links in a doc or spreadsheet before you leave.

    Which UTM parameters are required?

    Google Analytics says to always use utm_source, utm_medium and utm_campaign together. Those three answer where the visit came from, which channel brought it and which campaign it belongs to. utm_content and utm_term are optional. On X, utm_content is the most useful extra because it tells apart links in one campaign.

    Can I use UTM links in my X bio?

    Yes, you can use a UTM link in your X bio website field or in the bio text. Tag it with something like utm_content=bio_link so you can see how many visits your profile sends. Use the same campaign name as your other always-on links, like evergreen.
