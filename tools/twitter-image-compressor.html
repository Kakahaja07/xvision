How do I compress an image for Twitter?

To compress an image for Twitter (X), drop it into the free Twitter Image Compressor, set quality around 80%, cap the width if the photo is huge, and download the smaller JPEG, WebP or PNG. X's help page says photos can be up to 5MB, so the tool flags any file above that.

A photo straight off a modern phone can be several megabytes, and a long PNG screenshot can be bigger still. Compressing first means fewer failed uploads.

How to use the Twitter Image Compressor

  1. Drop one or more images on the box, or click it to pick files. You can add up to 20 at a time.
  2. Choose a format. JPEG suits photos, PNG suits screenshots and graphics, and WebP is handy for websites.
  3. Move the quality slider. Every file is compressed again a moment after you let go.
  4. Type a max width if your photos are very large. Leave it empty to keep the original width.
  5. Check the Before and After numbers, then tap Preview and flip between After and Before to compare.
  6. Press Download on a single file, or Download all to save every file one by one.

What do the numbers mean?

Each file shows its original size, its new size, the percent saved and its pixel size. Percent saved is (original size minus new size) divided by original size, times 100. The totals add up every file in the list.

So a 4.2 MB photo that comes out at 840 KB was cut by 80 percent. If the result is bigger than the original in the same format and size, the tool keeps your original file instead, because a bigger "compressed" file helps no one. Each row also says whether the file is under or over X's 5MB photo limit.

What are X's image size limits?

X's help pages list a 5MB limit for photos in posts and a 2MB limit for profile photos, as of October 2026. Animated GIFs can be 5MB on mobile and 15MB on the web. X accepts GIF, JPEG and PNG and does not accept BMP or TIFF.

JPEG, WebP or PNG: which should I pick?

Pick JPEG for photos, PNG for screenshots, charts and anything with small text, and WebP only for your own website or blog. X's help page lists JPEG and PNG for uploads, not WebP.

JPEG throws away detail your eye barely notices, which is why it shrinks photos so well. PNG keeps every pixel, so its quality slider does nothing here. To shrink a PNG, lower the max width or switch to JPEG. JPEG has no transparency, so the tool puts transparent areas on white.

Tips for small files that still look good

  • Start at 80 percent. Then zoom in on faces, hair and text before you download.
  • For big phone photos, a max width of about 2048 pixels is a sensible cap.
  • Always compress from the original file. Squeezing an already compressed JPEG again adds blocky marks.
  • For screenshots with words, try PNG first. If it is still too big, use JPEG at 90 percent.

Here's a quick example. Jonah, a fictional hiking blogger, has ten trail photos at around 6 MB each. He sets JPEG, quality 80 and max width 2048. Every row turns to "under 5MB", he previews the sunrise shot, and he saves the whole set with Download all.

Common mistakes to avoid

  • Saving photos as PNG. They often grow instead of shrinking.
  • Dropping quality to 30 percent to hit a tiny size. Smooth skies turn into bands and blocks.
  • Resizing below the size people view it at. A 600 pixel photo looks soft on a phone.
  • Posting WebP to X when the help page lists only GIF, JPEG and PNG.

Frequently Asked Questions

What is the maximum image size for Twitter?

The maximum photo size on X is 5MB per image, according to the X Help Center as of October 2026. Animated GIFs can be 5MB on mobile and 15MB on the web, and profile photos are limited to 2MB. The Twitter Image Compressor marks every file as under or over 5MB.

Does compressing an image reduce its quality?

Yes, JPEG and WebP compression removes some detail, but at around 80 percent quality many photos look very close to the original at normal size. PNG output is lossless, so it keeps every pixel. Use the Before and After preview in the compressor and zoom in on faces and text before you download.

Why did my PNG file get bigger after compression?

A PNG gets bigger when the original was already well compressed or when a photo is saved as PNG, because PNG keeps every pixel. If the format and size match, the Twitter Image Compressor keeps your smaller original. For photos, switch to JPEG or set a max width to cut the size.

Are my images uploaded to a server?

No, the Twitter Image Compressor never uploads your images. Each file is decoded, redrawn and re-encoded on a canvas inside your browser, and the download is created on your own device. That keeps private photos private and lets the tool work even when your connection is slow.

Can I compress several images at once?

Yes, you can drop up to 20 images at once into the Twitter Image Compressor. All files use the same format, quality and max width settings. Each one gets its own row with sizes and a Download button, and Download all saves every compressed file one after another.
